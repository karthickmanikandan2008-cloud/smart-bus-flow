⚙️ How SmartBus Flow Works

  1. System continuously monitors simulated bus movement.
  2. Current speed and gap are displayed.
  3. If buses become too close, bunching risk is detected.
  4. Operator can select holding time for each bus.
  5. New gaps are calculated.
  6. Passenger waiting time is estimated.
  7. Improvement is displayed.
